# Stundenplaner

Interaktiver Wochenplan für den Praxisalltag (30-Min-Slots, mehrere Mitarbeiter, farbige Aufgabentypen, Empfangs-Übersicht).

**Live-Version:** https://lollylan.github.io/Stundenplaner/

## Features

- 5 Tagesansichten (Mo–Fr) mit 30-Min-Slots, 8:00–19:00 Uhr
- Beliebige Mitarbeiter-Spalten, frei umbenennbar und erweiterbar
- 11 vordefinierte Aufgabentypen, eigene Aufgaben mit eigener Farbe anlegbar
- Bearbeiten-Modus für Strukturänderungen, Normalmodus zum Befüllen
- Übersicht für den Empfang: zeigt pro Aufgabentyp, wann/wo Termine vergeben werden können
- Druck-Layout (A4 quer)
- Export/Import als JSON
- Daten werden lokal im Browser gespeichert (`localStorage`)

## Bedienung

1. Aufgabe in der Legende anklicken (= Pinsel aktivieren)
2. Zellen im Tagesplan anklicken, um die Aufgabe einzutragen
3. Über „Bearbeiten" Aufgabentypen und Spalten anpassen
4. Tab „Übersicht Empfang" für die Zusammenfassung pro Terminart

## Hosting

Die Datei ist 100% statisch (HTML/CSS/JS, keine Abhängigkeiten außer Google Fonts). Sie kann auch lokal geöffnet werden – einfach `index.html` doppelklicken.
